DESCRIPTION
----------------------------------------------------------------------
Automated data validation framework. YAML expectations, 12+ check types, statistical anomaly detection, HTML reports with trend tracking.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - pandas
  - pydantic
  - pyyaml
  - jinja2
  - scipy
  - click
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * YAML validation expectations
  * 12+ check types
  * KS-test anomaly detection
  * HTML quality reports
  * Trend tracking
  * CI/CD exit codes

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  CSV data and expectations

  Example:
    sentinel validate --data orders.csv --expectations rules.yaml

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Quality report

  Example:
    Validation: 12/14 checks passed (score: 85.7%)
